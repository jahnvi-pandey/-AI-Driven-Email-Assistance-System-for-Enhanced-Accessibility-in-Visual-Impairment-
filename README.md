AI-Powered Email Listening and Response System for the Visually Impaired

The project aims to develop a **voice-based email system** that enables visually impaired users to **send, receive, read, and manage emails independently** using speech commands. It integrates **Speech-to-Text (STT)** for converting voice into text and **Text-to-Speech (TTS)** for reading emails aloud, making email communication accessible without relying on screen readers. 

Technologies Used:
* Python, Java, HTML, CSS, JavaScript, AJAX
* Speech Recognition
* Google Text-to-Speech (gTTS)
* SMTP, IMAP, SQLite
* AI and Natural Language Processing (NLP) 

Key Features:
* Voice-based login
* Compose emails using voice
* Read inbox emails aloud
* Reply, forward, and manage emails
* Support for attachments
* AI-assisted voice interaction 

Advantages:
* Improves accessibility
* Enables independent email management
* Faster communication
* Enhances digital inclusion and privacy
* Supports smart device integration 

Limitations:
* Requires internet and compatible devices
* Speech recognition may fail in noisy environments
* Security and privacy concerns
* Difficulty understanding complex emails 

Future Scope:
* Mobile application support
* Better AI-based voice recognition
* Email summarization
* Personalized user experience
* Stronger security and wearable device integration
